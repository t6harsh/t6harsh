## Projects

#### [DPF Soot Load Prediction](https://github.com/t6harsh/Tensor-Planet)
End-to-end predictive maintenance system for diesel particulate filters. Synthetic data generation, temporal feature engineering, XGBoost with MLflow tracking. RMSE ~0.87%.<br>
<sub>`Python` `XGBoost` `FastAPI` `Docker` `MLflow`</sub>

#### [Liver Disease Prediction](https://github.com/t6harsh/Liver-Disease-Prediction)
Complete supervised ML pipeline for clinical diagnosis with EDA, SMOTE class balancing, and SHAP interpretability analysis.<br>
<sub>`Python` `Scikit-learn` `XGBoost` `SHAP`</sub>

#### [System Threat Forecasting](https://github.com/t6harsh/ML-Project)
Malware prediction from high-dimensional system telemetry data. feature engineering, PCA, and gradient boosting ensembles with cross-validation.<br>
<sub>`Python` `LightGBM` `XGBoost` `Scikit-learn`</sub>
